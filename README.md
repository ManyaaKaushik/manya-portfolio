# Manya — A Polymath's Garden

Run `node serve.mjs`, then open http://localhost:3001. Deployable static files are in `dist/`. No package installation or build step is required. Syntax check: `node --check dist/script.js`.

Created from Manya's Figma narrative/moodboard and the real content in the existing portfolio export. Existing case studies open at manyaa.me; the original `../site` is preserved.

See PRODUCT.md, DESIGN.md and ASSETS.md for content, design decisions and asset provenance. The Sites project identity is tracked in `.openai/hosting.json`; preserve it on later publication.
